HeadTrack-Mouse: Multimodal Assistive HCI

Decoupled Dual-Sensor Fusion & Accessibility Control

Decoupled Sensor Fusion Architecture

Overcomes traditional single-sensor webcam fatigue by decoupling the control axes across dedicated hardware nodes:

  • X-Axis Tracking: MediaPipe Face Mesh processes 478 3D facial landmarks at 60 FPS for horizontal head rotation.
  • Y-Axis Tracking: Arduino reading MPU-6050 accelerometer/gyroscope pitch tilt to prevent vertical drift.
  • Edge Voice Command: ESP32 with INMP441 I2S digital microphone runs Voice Activity Detection (VAD) to trigger screen boundary locking.
  • Adaptive Filtering: Exponential Smoothing removes micro-jitter while supporting lip-purse gesture detection for 25% precision mode.
  • Desktop Dashboard: PyQt6 management console integrating Selenium WebDriver for automated session authentication.

Hujou3: Distributed Ambient Intelligence Hub

Multi-Node Secure IoT Controller & Deterministic FSM

Distributed Architecture & Protocol Hardening

  • 3-Tier Topology: Isolates concerns between an ESP32 audio-sensing node, Python NLP serial bridge (921,600 baud), and an Arduino R4 WiFi actuation hub.
  • Deterministic FSM: 9-state state machine orchestrating OLED menus, DFPlayer audio soundscapes, and Tuya Smart Lighting.
  • Cryptographic Cloud Requests: Communicates with Tuya OpenAPI via HTTPS/TLS using dynamically calculated HMAC-SHA256 request signatures.
  • Anti-Replay Network Security: NTP-synchronized epoch timestamps enforce a ±5-second acceptance window on local JSON HTTP commands.
  • Zero-Config Discovery: Local mDNS (noura-hub.local) resolves dynamically across nodes without fixed IP addresses.
