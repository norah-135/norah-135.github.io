AeroMedic: Systems Engineering & Sprint 1 Highlights

Autonomous Cyber-Physical Emergency Telemetry Ecosystem
V-Model Lifecycle: Agile Sprint 1 Base Reached
Bottom of the V: Implementation Baseline

Following standard Systems Engineering V-Model principles, the top-down decomposition on the left wing (System Requirements Analysis and Architecture Design) has concluded. We have reached the bottom slope of the V with Agile Sprint 1, delivering the core hardware baseline (schematic, wearable PCB design, and verified cloud telemetry pipeline). The subsequent sprints will expand hardware-in-the-loop firmware before ascending the right wing for SITL drone integration and field validation.

1. 3D Assembly Model

Assembled 3D PCB Physical Render

Physical clearance and mechanical collision inspection for the custom wearable PCB. Confirmed component heights (ESP32-C3, Semtech SX1262 LoRa module, and optical PPG sensors) to guarantee perfect fitment within the drone payload dispatch bay and the wrist strap.

2. PCB Layout & Routing

2D Multi-Layer PCB Traces & Routing

Multi-layer routing routed in EasyEDA. Implemented $50\Omega$ controlled impedance matching on the LoRa RF transmission trace, dedicated star-grounding to isolate digital noise from sensitive bio-sensors, and ground plane pouring for EMI suppression.

3. Telemetry Topology

MQTTS Cloud Telemetry Pipeline Architecture

Low-latency, publish-subscribe telemetry architecture decoupling the local wearable node and mobile dispatch application from backend infrastructure. Hierarchical topic tree (aeromedic/emergency/alerts) engineered for high-concurrency emergency routing under sub-second latency.

4. Live System Execution

End-to-End Emergency Dispatch Execution (MOV Demo)

Real-time validation of Sprint 1: Actuating the SOS button on the Flutter Hub triggers immediate payload construction containing live biomedical metrics (SpO2: 96%, HR: 82 BPM). Telemetry is securely transported via WebSockets (WSS port 8084) to the cloud broker, instantaneously confirmed by a synchronous PublishAck packet.

5. Electrical Schematic

Full Circuit Schematic Diagram (EasyEDA)

Complete circuit design detailing power regulation rails (LDO 3.3V), lithium battery charging and protection sub-circuits, decoupled I2C communication buses for the ICM-42688-P IMU and MAX30102 oximeter, and SPI connections to the SX1262 LoRa transceiver.

HeadTrack-Mouse: Multimodal Assistive HCI

Decoupled Dual-Sensor Fusion & Accessibility Control

Decoupled Sensor Fusion Architecture

Overcomes traditional single-sensor webcam fatigue by decoupling the control axes across dedicated hardware nodes:

  • X-Axis Tracking: MediaPipe Face Mesh processes 478 3D facial landmarks at 60 FPS for horizontal head rotation.
  • Y-Axis Tracking: Arduino reading MPU-6050 accelerometer/gyroscope pitch tilt to prevent vertical drift.
  • Edge Voice Command: ESP32 with INMP441 I2S digital microphone runs Voice Activity Detection (VAD) to trigger screen boundary locking.
  • Adaptive Filtering: Exponential Smoothing removes micro-jitter while supporting lip-purse gesture detection for 25% precision mode.
  • Desktop Dashboard: PyQt6 management console integrating Selenium WebDriver for automated session authentication.

Hujou3: Distributed Ambient Intelligence Hub

Multi-Node Secure IoT Controller & Deterministic FSM

Distributed Architecture & Protocol Hardening

  • 3-Tier Topology: Isolates concerns between an ESP32 audio-sensing node, Python NLP serial bridge ($921.6\text{k baud}$), and an Arduino R4 WiFi actuation hub.
  • Deterministic FSM: 9-state state machine orchestrating OLED menus, DFPlayer audio soundscapes, and Tuya Smart Lighting.
  • Cryptographic Cloud Requests: Communicates with Tuya OpenAPI via HTTPS/TLS using dynamically calculated HMAC-SHA256 request signatures.
  • Anti-Replay Network Security: NTP-synchronized epoch timestamps enforce a $\le 5\text{s}$ acceptance window on local JSON HTTP commands.
  • Zero-Config Discovery: Local mDNS (noura-hub.local) resolves dynamically across nodes without fixed IP addresses.
