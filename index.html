AeroMedic: Deep Technical Architecture

Autonomous Cyber-Physical Emergency Telemetry Ecosystem

System Layering & Hardware Co-Design

Designed as a resilient fail-safe ecosystem adhering to Systems Engineering V-Model principles:

  • Physical Layer: Custom multi-layer wearable PCB designed in EasyEDA housing an ESP32-C3 MCU, Semtech SX1262 LoRa module, MAX30102 pulse oximeter, and ICM-42688-P 6-axis IMU. Smart payload delivery box modeled in Autodesk Fusion 360 with chemical oxygen thermal barriers.
  • Firmware & BLE: ESP-IDF (FreeRTOS) NimBLE stack configured for connectionless Non-Directed Advertising (Beacon Mode), eliminating user Bluetooth pairing steps.
  • Cloud & Dispatch Link: Cross-platform Flutter client publishing encrypted emergency triggers via MQTTS to an EMQX Cloud Broker with fallback LoRa gateway routing.

HeadTrack-Mouse: Multimodal Assistive HCI

Decoupled Dual-Sensor Fusion & Accessibility Control

Decoupled Sensor Fusion Architecture

Solves traditional webcam tracking fatigue by partitioning axis controls:

  • X-Axis Control: MediaPipe Face Mesh processing 478 3D landmarks at 60 FPS for horizontal head rotation.
  • Y-Axis Control: Arduino Uno R4 WiFi reading MPU-6050 accelerometer/gyroscope pitch tilt to prevent vertical drift.
  • Voice Boundary Locking: ESP32 with INMP441 I2S microphone captures real-time audio with Voice Activity Detection (VAD) to lock the cursor to top/bottom screen edges.
  • Adaptive Filtering: Exponential response curves and moving averages reduce micro-jitter while supporting lip-purse precision mode (25% speed).

Hujou3: Distributed Ambient Intelligence Hub

Multi-Node Secure IoT Controller & Deterministic FSM

Distributed Topologies & Security Hardening

  • 3-Tier Topology: ESP32 audio sensing node ➔ High-speed Python NLP serial bridge (921,600 baud) ➔ Arduino R4 WiFi actuation hub.
  • Deterministic FSM: 9-state state machine managing local OLED displays, DFPlayer audio soundscapes, and cloud lighting.
  • Anti-Replay Network Security: NTP-synchronized epoch timestamps enforce a ±5-second validity window, blocking captured packet injection.
  • Zero-Config Discovery: Local mDNS (noura-hub.local) resolves dynamically across nodes without hardcoded IP dependencies.
