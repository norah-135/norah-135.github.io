HeadTrack-Mouse: Multimodal Assistive HCI

Decoupled Dual-Sensor Fusion & Hands-Free Productivity Ecosystem

System Overview & Decoupled Architecture

Designed to eliminate fine motor control barriers for users with physical mobility challenges, carpal tunnel syndrome, or RSI[cite: 1]. Unlike traditional single-sensor eye/face trackers that cause rapid muscle fatigue, this system decouples control axes across three distinct hardware and software modalities to achieve sub-10ms latency and millimeter cursor precision[cite: 1]:

  • Horizontal X-Axis Control: MediaPipe Face Mesh tracking 478 3D landmarks at 60 FPS to detect natural horizontal head rotation[cite: 1]. Includes precision Slow Mode (25% speed via lip-purse gesture) and mouth-pull gestures for left/right clicks[cite: 1].
  • Vertical Y-Axis Control: An Arduino Uno R4 WiFi processes 6-axis MPU-6050 accelerometer and gyroscope data at 100 Hz, mapping vertical head pitch through exponential acceleration curves and adaptive smoothing algorithms[cite: 1].
  • Edge Voice Lock Zones: An ESP32 connected to an INMP441 I2S digital microphone runs Voice Activity Detection (VAD) streaming audio over high-speed serial[cite: 1]. Commands ("up", "down", "release") instantly anchor the cursor to top/bottom 5% screen boundaries without physical neck craning[cite: 1].
Multimodal Architecture Pipeline

Hardware-Decoupled Input Routing Pipeline

Signal flow schematic demonstrating the physical separation of concerns: The horizontal cursor plane is mapped through MediaPipe facial landmarks, vertical tracking is handled via MPU-6050 physical tilt via I2C, and screen boundary anchoring is executed by an independent ESP32 edge audio node running Voice Activity Detection (VAD)[cite: 1].

Hujou3: Distributed Ambient Intelligence Hub

Multi-Node Secure IoT Controller & Deterministic FSM

Distributed Architecture & Protocol Hardening

  • 3-Tier Topology: Strictly isolates concerns between an ESP32 audio-sensing node, Python NLP serial bridge (921,600 baud), and an Arduino R4 WiFi actuation hub.
  • Deterministic FSM: 9-state state machine orchestrating OLED menus, DFPlayer audio soundscapes, and Tuya Smart Lighting.
  • Cryptographic Cloud Requests: Communicates with Tuya OpenAPI via HTTPS/TLS using dynamically calculated HMAC-SHA256 request signatures.
  • Anti-Replay Network Security: NTP-synchronized epoch timestamps enforce a ≤ 5s acceptance window on local JSON HTTP commands.
  • Zero-Config Discovery: Local mDNS (noura-hub.local) resolves dynamically across nodes without fixed IP addresses.
